# Maintenance Project – UniTime System

## 📌 Project Description
This project focuses on maintaining and improving the UniTime system.  
The main goal is to enhance code quality, fix bugs, and improve maintainability.

## 🔧 Features & Changes
- Refactored large enums (Right.java) into smaller enums:
  - CourseRight
  - EventRight
  - RoomRight
- Improved code readability and structure
- Reduced complexity in security rights handling

## 📊 Static Code Analysis
We used SonarQube to analyze the code:
- Identified maintainability issues
- Found duplicated code (13.3%)
- Highlighted reliability problems
- Generated a full analysis report

## 🛠 Tools Used
- SonarQube
- GitHub
- Jira (for issue tracking)

## 🎫 Change Management
The issue "Refactor Right enum to improve maintainability" was created and tracked using Jira.  
It was implemented, tested, and marked as done.

## 👥 Team Workflow
- Work pushed using GitHub commits
- Each change documented and tracked
- Code improvements linked with Jira issues
